# Analysis notebook

Start with `churnprediction.ipynb` and run its cells in order using the project virtual environment.

The notebook currently loads the raw data and performs initial profiling. Markdown sections reserve space for each of the six project phases. Complete these sections as the project progresses; they are not finished analyses.

Run with the working directory at the repository root or inside this repository. Paths are resolved from the location of `datasets/TelecomChurnData.csv`, so no machine-specific path is required.

Keep raw data unchanged. Save reviewed reports in `outputs/reports/`, charts in `outputs/charts/`, and derived customer tables in `outputs/data/`. Clear cell outputs before committing to avoid stale results and customer-level previews in version history.
